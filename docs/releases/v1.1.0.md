## Changes

- Refresh the workspace with consistent shadcn/ui controls, accessible dialogs,
  menus, forms, tabs, and tables across light and dark themes.
- Add interface font and font-size customization in Settings > Appearance, below
  the color palettes, with a live preview, automatic saving, and a reset action.
  Choose a preset or enter an installed font name; unavailable fonts fall back
  to the default font. Font sizes range from 12 to 20 px.
- Scale roster text and numeric columns with the selected font size, including
  narrow windows, keep palette previews readable at large font sizes, and
  restore typography preferences on startup.
- Keep the page scrollbar visible and the title bar pinned when opening select
  menus, without shifting the page or interrupting keyboard navigation.
- Remove the redundant local-preferences badge from settings page headings.
- Default missing primary-region preferences to automatic detection while
  preserving saved manual selections and other settings.
- Sort the roster by ship and allow selected watch marks to be toggled off in
  both player details and roster menus while preserving notes.

## Validation

- `node scripts/verify-release-version.mjs v1.1.0` passed for all five workspace
  packages and the matching release tag value.
- `pnpm check` passed: type checking, 214 regression tests in 18 files, and
  design-token validation.
- `pnpm dist:win` passed, including the web and desktop production builds and
  both Windows executable formats.
- `pnpm smoke:desktop` and `pnpm verify:package` passed with isolated application
  data. Packaged validation used the generated v1.1.0 portable executable.
- Desktop validation covered 240 page combinations, 144 dialog states, and
  16 typography combinations at 12 and 20 px, in light and dark themes at
  widths of 1440 and 390 CSS pixels. It also checked select-menu scrollbars,
  sticky headers, keyboard navigation, autosave, and reset behavior.
- The initial packaged verification reached its 120-second timeout before the
  expanded smoke suite finished. After increasing the limit to 180 seconds,
  the complete rerun passed.
- Initial CI reported undersized palette previews in narrow layouts. Compact
  palette-card padding now leaves more room for the previews at large font sizes.
- A CI retry exposed asynchronous client discovery changing document height
  during a scrollbar check. The check now waits for discovery and verifies
  scrollbar visibility without requiring the document height to stay fixed.
- `pnpm verify:updates` passed: update metadata, installer SHA-512 and size,
  installer blockmap, and portable companion file.
- Live API checks were not run; `WG_APPLICATION_ID` was not set.
- Update validation covered generated metadata and simulated updater behavior.
  An actual v1.0.6-to-v1.1.0 installation was not performed.
