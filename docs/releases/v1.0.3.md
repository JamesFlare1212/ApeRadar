## Changes

- Refresh the bundled ship catalog to WG encyclopedia version 15.9.0 (2026-10-07),
  covering 1,026 ships while retaining legacy entries absent from the public API.
- Add `pnpm ships:update` for validated bilingual catalog refreshes and
  `--names-only` for offline Chinese name restoration. Report missing ID mappings
  and names requiring review after each update.
- Fetch missing ship details in the background for ASIA, NA, and EU, deduplicate
  requests, and persist successful results locally for later offline use without
  blocking lineup imports or player statistics.
- Restore original Chinese ship names using 201 ship ID mappings, with English
  aliases as fallback. Cover all Japanese and Pan-Asian ship types, including
  previously omitted battleships and ARP collaboration ships. Apply the same
  names to API results, cached entries, historical snapshots, and exports.

## Validation

- `node scripts/verify-release-version.mjs v1.0.3` passed for all five workspace
  packages and the matching release tag value.
- `pnpm check` passed: type checking, 188 regression tests in 16 files, and
  design-token validation.
- `pnpm dist:win` passed, including the web and desktop production builds and
  both Windows executable formats. Vite reported a non-fatal JavaScript
  chunk-size warning.
- `pnpm smoke:desktop` and `pnpm verify:package` passed using isolated application
  data and the generated v1.0.3 portable executable.
- `pnpm verify:updates` passed: update metadata, installer SHA-512 and size,
  installer blockmap, and portable companion file.
- `pnpm test:api:live` passed the official ASIA, NA, and EU player API checks and
  targeted bilingual ship lookups, including original Chinese names for Yamato,
  Xuan Wu, and ARP Yamato. EU and ASIA Vortex checks passed; NA and RU Vortex
  checks were partial because some details were unavailable.
- A separate full catalog audit found no missing public ship IDs across ASIA,
  NA, and EU. All 201 bundled Japanese and Pan-Asian ships have ID mappings;
  only the two valid submarine identifier names remain without Chinese text.
- Update validation covered generated metadata and simulated updater behavior.
  An actual v1.0.2-to-v1.0.3 installation was not performed.
