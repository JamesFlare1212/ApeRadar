## Changes

- Show an API connection alert only when a service is degraded or unavailable,
  with a shortcut to connection settings. Clear the alert when the connection
  recovers and keep normal or pending checks quiet.
- Match the application background to the sidebar and round the workspace's
  left corners when the sidebar is expanded for a consistent window surface.

## Downloads

- `ApeRadar-Next-Setup-2.0.2-x64.exe`: Windows x64 installer.
- `ApeRadar-Next-2.0.2-x64.exe`: Windows x64 portable application.
- `latest.yml` and `ApeRadar-Next-Setup-2.0.2-x64.exe.blockmap` support application updates.
