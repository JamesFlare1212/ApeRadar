## Changes

- Remove the extra inset workspace frame so the application fills the desktop
  window and follows its native rounded perimeter.
- Keep long pages scrolling inside the workspace while the title bar and
  sidebar stay fixed, and reset scrolling when navigating between pages.
- Restore rounded hover highlights on window controls and leave room for
  keyboard focus rings around the minimize, maximize, and close buttons.
- Fix Windows development startup so `pnpm dev` opens the Electron window
  instead of leaving it hidden.

## Downloads

- `ApeRadar-Next-Setup-2.0.1-x64.exe`: Windows x64 installer.
- `ApeRadar-Next-2.0.1-x64.exe`: Windows x64 portable application.
- `latest.yml` and `ApeRadar-Next-Setup-2.0.1-x64.exe.blockmap` support application updates.

## Validation

- `node scripts/verify-release-version.mjs v2.0.1` passed for all five workspace
  packages and the matching release tag value.
- `pnpm check` passed: type checking, 220 regression tests in 19 files, and
  design-token validation.
- `pnpm dist:win` passed, including `pnpm build`, web and desktop production
  builds, the Windows x64 installer, and the portable executable.
- `pnpm verify:updates` passed: update metadata, installer SHA-512 and size,
  installer blockmap, and portable companion file.
- `pnpm smoke:desktop` passed with isolated application data, including
  application bounds, internal scrolling, navigation, and simulated updates.
- `pnpm verify:package` passed against the generated
  `ApeRadar-Next-2.0.1-x64.exe` with isolated application data.
- Desktop appearance checks passed for 240 page combinations, 144 dialog
  states, and 16 typography combinations across light and dark themes at
  widths of 1440 and 390 CSS pixels.
- Windows development startup was checked with `pnpm dev`; the application
  window became visible after disabling the hidden-process launch option.
- Live API checks were not run because `WG_APPLICATION_ID` was not set.
- Update-feed checks and simulated updater tests do not establish an actual
  version-to-version installation. A v2.0.0-to-v2.0.1 installation was not performed.
