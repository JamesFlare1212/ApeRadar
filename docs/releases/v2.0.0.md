## Changes

- Redesign workspace navigation with a collapsible sidebar, clearer settings
  sections, and streamlined page headings across light and dark themes.
- Refresh controls, icons, tooltips, player details, and responsive layouts
  with consistent shadcn/ui components.
- Keep roster rows compact and align hidden-player rows across interface font
  sizes, with clearer ship names, status badges, and watch actions.
- Simplify roster workflows around automatic game detection and text summaries;
  remove manual roster import and CSV export.
- Show actionable settings validation errors, link each error to its field,
  and preserve unsaved drafts while invalid values are corrected.
