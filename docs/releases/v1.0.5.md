## Changes

- Use compact, icon-only navigation in narrow windows on both the workspace and
  Settings pages. Place the Settings back button on the left and the update
  action on the right, preserve tooltips and accessible names, and keep keyboard
  focus in visual order.
- Match the Settings back shortcut to the workspace icon buttons and keep
  navigation controls visible without horizontal clipping.
- Keep the game directory field and its browse/check actions on one row in
  narrow windows, and align Settings inputs and selectors at a consistent height.
- Default new installations and restored preferences to WG Public API while
  preserving existing saved source choices. Configure the WG Application ID
  through the configuration file or environment variable instead of Settings.

- `ApeRadar-Next-Setup-1.0.5-x64.exe`: Windows x64 installer.
- `ApeRadar-Next-1.0.5-x64.exe`: Windows x64 portable application.

- `node scripts/verify-release-version.mjs v1.0.5` passed for all five workspace
  packages and the matching release tag value.
- `pnpm check` passed: type checking, 190 regression tests in 16 files, and
  design-token validation.
- `pnpm dist:win` passed, including the web and desktop production builds and
  both Windows executable formats. Vite reported a non-fatal JavaScript
  chunk-size warning.
- `pnpm smoke:desktop` and `pnpm verify:package` passed using isolated application
  data and the generated v1.0.5 portable executable.
- `pnpm verify:updates` passed: update metadata, installer SHA-512 and size,
  installer blockmap, and portable companion file.
- Narrow-window layout measurements verified navigation at 320, 375, and 460px,
  Settings control heights, the leftmost back action, and keyboard focus order.
- `pnpm test:api:live` was skipped because `WG_APPLICATION_ID` was not set.
- Update validation covered generated metadata and simulated updater behavior.
  An actual v1.0.4-to-v1.0.5 installation was not performed.
