## Changes

- Start game monitoring automatically on launch and follow changes to the saved
  game directory. Remove the manual start and pause controls, show monitoring
  notices only when attention is needed, and retry automatically after errors.
- Keep sidebar settings and update buttons at fixed sizes, place them on the
  same row when space permits, and wrap them in the collapsed sidebar.
- Use an icon-only settings shortcut while preserving its accessible name and
  tooltip. Align the update action with narrow-screen navigation icons and add
  a visible update label.
- Keep light and dark palette previews circular when appearance cards shrink.
