## Changes

- Make light-theme button hover and sidebar selection backgrounds easier to see
  across all six palettes, with a flat selected state and no edge outline.
- Size the Settings and Back shortcuts to their contents, show a visible Back
  label, and keep the update action aligned at the opposite edge of the sidebar.
- Add a shared title bar showing the current section and page, with desktop
  minimize, maximize/restore, and close controls.

## Downloads

- `ApeRadar-Next-Setup-1.0.6-x64.exe`: Windows x64 installer.
- `ApeRadar-Next-1.0.6-x64.exe`: Windows x64 portable application.
- `latest.yml` and `ApeRadar-Next-Setup-1.0.6-x64.exe.blockmap` support application updates.

## Validation

- `node scripts/verify-release-version.mjs v1.0.6` passed for all five workspace
  packages and the matching release tag value.
- `pnpm check` passed: type checking, 190 regression tests in 16 files, and
  design-token validation.
- `pnpm dist:win` passed, including the web and desktop production builds and
  both Windows executable formats. Vite reported a non-fatal JavaScript
  chunk-size warning.
- `pnpm smoke:desktop` and `pnpm verify:package` passed with isolated application
  data, the latter using the generated v1.0.6 portable executable.
- `pnpm verify:updates` passed: update metadata, installer SHA-512 and size,
  installer blockmap, and portable companion file.
- Browser measurements checked hover and selected text contrast across all six
  palettes in both themes and confirmed the final light-theme selection has a
  transparent border.
- Live API checks were not run because this release changes presentation only.
- Update validation covered generated metadata and simulated updater behavior.
  An actual v1.0.5-to-v1.0.6 installation was not performed.
