## Changes

- Match tier XI supership markers to the game's sharp, solid five-pointed star.
  Keep the marker inline with the ship name without increasing roster row height.
- Prevent delayed responses from reverting newer battle results or settings, and
  preserve watch-note drafts when saving fails.
- Improve statistics request cancellation, timeout recovery, and partial-result
  persistence when changing battles, connection settings, or closing the app.
- Detect rewritten arena files even when their size and timestamp are unchanged,
  and prevent duplicate desktop processes from sharing application data.
- Keep verified update downloads available for installation retries and reject
  obsolete installation attempts.
- Update Electron and application dependencies.

## Validation

Local release validation ran on November 16, 2026, using Node.js 24.22.3,
pnpm 10.34.6, and Electron 45.2.3.

- `node scripts/verify-release-version.mjs v2.0.3` passed for all five workspace
  packages and the intended release tag.
- `pnpm check` passed: type checking, 263 regression tests in 23 files, and
  design-token validation.
- `pnpm dist:win` passed, including production builds and both Windows x64
  executables listed above.
- `pnpm verify:updates` passed: installer version and filename, SHA-512 and size,
  installer blockmap, and portable companion file.
- `pnpm verify:package` passed against the generated
  `ApeRadar-Next-2.0.3-x64.exe` with isolated application data. The local executable
  identity and SHA-256 are recorded in the
  [packaged report](https://github.com/JamesFlare1212/ApeRadar/blob/v2.0.3/artifacts/packaged-validation.json).
- `pnpm smoke:desktop` passed with isolated synthetic game-client and application
  data, including snapshot ordering, failed watch-note save and retry, a real
  second-process startup check, and simulated updater states.
- Desktop and packaged appearance checks passed for 240 page combinations,
  144 dialog states, 16 typography combinations, and 12 supership-marker
  combinations across light and dark themes at 1440 and 390 CSS pixels.
  Marker checks cover sharp regular-star geometry, solid fill, text-relative
  sizing, inline alignment, and unchanged Roman numerals for other tiers.
- `pnpm test:api:live` completed with all three official NA, EU, and ASIA
  functional checks, the bilingual ship-encyclopedia checks, and the missing-ID
  negative check passing. The initial official ASIA health probe encountered a
  network failure even though its subsequent functional pipeline passed.
  Vortex EU and ASIA functional checks passed; NA and RU returned partial details.
  These are not complete Vortex passes. See the
  [live API report](https://github.com/JamesFlare1212/ApeRadar/blob/v2.0.3/artifacts/live-api-probe.json).
- Local metadata verification and simulated updater tests do not establish a
  real version-to-version installation. A v2.0.2-to-v2.0.3 installed upgrade,
  including network-failure, interrupted-download, installer-cancellation, and
  restart scenarios, was not performed. Local packaging does not replace an
  installed application.

The tag-triggered release workflow independently builds and validates the
published executables; the local executable digest above does not identify a
separately generated CI artifact.
